HOW TO PUBLISH ON GITHUB PAGES
1. Sign in at github.com and create a new PUBLIC repository named YOURUSERNAME.github.io
2. Choose "Add file" > "Upload files" and upload index.html and the assets folder contents, keeping the assets/Anagha_VS_CV.pdf path.
   Alternative: extract this ZIP locally and upload the files via GitHub's upload interface (GitHub preserves folders when you drag the folder).
3. Commit changes. Visit Settings > Pages and set Build and deployment > Source to "Deploy from a branch", branch "main", folder "/ (root)". Save.
4. After deployment, open https://YOURUSERNAME.github.io

BEFORE PUBLISHING
- Review wording and author names, particularly the 2025 publication's author list, against the final published article.
- Confirm whether the October 2026 working paper is publicly available; no download link is included for it.
- Add LinkedIn/ResearchGate links once exact profile URLs are provided.
- If you update the CV, replace assets/Anagha_VS_CV.pdf with the new file using the same filename.

The site is a static site and does not require a hosting subscription or build tools. Google Fonts are loaded online; fallback fonts display if offline.
